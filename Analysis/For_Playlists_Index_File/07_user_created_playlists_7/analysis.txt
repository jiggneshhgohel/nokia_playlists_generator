Following is the analysis of playlists index file named `listinfo.data` containing 7 user-created playlists on phone.

The hex-dump of that file can be found in `hex_dump.txt` in this file's folder.

------

Based on the analysis done for `listinfo.data` containing entries for 3 and 4 user-created playlists (refer `analysis.txt`
in `Analysis/For_Playlists_Index_File/03_user_created_playlists_three` and `Analysis/For_Playlists_Index_File/03_user_created_playlists_four`
folders

we will investigate only the last two entries because

all entries except last should occupy 532 bytes.
last-entry should contain 524 bytes.

~~~~~~~~~~~

Eleventh entry starts in 149th row at 28th byte (offset 0x14EB) and ends in 164th row at 19th byte (offset 0x16FE).

Twelfth entry starts in 164th row at 20th byte (offset 0x16FF) and ends in 179th row at 3rd byte (offset 0x190A).

Let's subtract the hex offsets to find the occupied bytes.

Eleventh entry:
  16FE - 14EB = 213 = 531 in decimal. Because of subtraction we loose one count so include it back. So that becomes 532 bytes.

Twelfth entry:
  190A - 16FF = 20B = 523 in decimal. Adding back the one count we get 524 bytes.

~~~~~~~~~~~
