Following is the analysis of playlists index file named `listinfo.data` containing 3 user-created playlists on phone.
The hex-dump of that file can be found in `hex_dump.txt` in this file's folder.

------

In Ghex editor

Each row contains 36 bytes.

In 1st row the header

MUSICARRAY SAVEFILE 01.00.0

occupies 27 bytes. Then it is followed by 8 null bytes. Then First entry starts.

First entry starts in 1st row at 36th byte (offset 0x23) and ends in 16th row at 27th byte (offset 0x236).
Note: Offset can be found in ghex editor on bottom left when clicking a byte.

Second entry starts in 16th row at 28th byte (offset 0x237) and ends in 31st row at 19th byte (offset 0x44A).

Third entry starts in 31st row at 20th byte (offset 0x44B) and ends in 46th row at 11th byte (offset 0x65E).

Fourth entry starts in 46th row at 12th byte (offset 0x65F) and ends in 61st row at 3rd byte (offset 0x872).

Fifth entry starts in 61st row at 4th byte (offset 0x873) and ends in 75th row at 31st byte (offset 0xA86).

Sixth entry starts in 75th row at 32nd byte (offset 0xA87) and ends in 90th row at 23rd byte (offset 0xC9A).

Seventh entry starts in 90th row at 24th byte (offset 0xC9B) and ends in 105th row at 15th byte (offset 0xEAE).

Eighth entry starts in 105th row at 16th byte (offset 0xEAF) and ends in 119th row at 35th byte (offset 0x10BA).

First entry is default created temp playlist name.
Second to Fifth entries are default playlists name.
Sixth to Eighth entries are user created playlists name.
