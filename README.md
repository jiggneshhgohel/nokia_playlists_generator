# Introduction

Let's say you have a latest Nokia feature-phone supporting a music-player
allowing you to create playlists.

Usually Nokia feature-phones running S30+ and Unisoc architecture supports 4G capabilities and comparatively higher RAM like 64MB or 128 MB. The music players on such configuration allows creating playlists in music player.

When you create a playlist through phone's music-player it should get created under `System/Mp3_res` path on SD_CARD inserted into the phone.

Now let's assume that you own a huge offline-collection of music and you wish to use your phone as a music-player and you prefer organizing your music as playlists, wherein each playlist can contain a lot of songs (say at-least 30).

Now using the phone creating multiple playlists (say 30+) and adding songs to each of them, can become very very tedious and annoying. So to solve that problem this utility is created.

_**Note: At the time of writing this, this utility was successfully used by the author to generate 70-100 playlists for *Nokia 220 4G* model launched in 2024 in India. So this utility can be used by any model sharing the architecture and features with that model.**_

# Usage prerequisites

1. You need to have latest Ruby installed on your personal-computer (PC) from which you would be using this utility.

   For installation instructions please follow [this](https://www.ruby-lang.org/en/documentation/installation/) official guide.

2. Download this utility and extract to a desired location, say `/home/jignesh`.
   The utility's path should be `/home/jignesh/nokia_playlists_generator`.
   Henceforth this path will referred to as `UTILITY_ROOT`.

3. A USB Type-A to USB Type-C data-cable (not a charging cable) to connect your
   Nokia feature-phone to PC for transferring playlist files generated by this utility.


# Usage

Let's say you have your music-collection on your personal-computer (PC) at a path, say `/home/jignesh/MY_MUSIC_COLLECTION`. Henceforth this path will referred to as `PC_ROOT_PATH_TO_MUSIC_COLLECTION`.

Next let's say in the folder referenced by `PC_ROOT_PATH_TO_MUSIC_COLLECTION` you have your music organized in following manner:

```
Song-1.mp3
Song-2.mp3
Song-3.mp3

folder_1
  Song-4.mp3

  folder_1_1
    Song-5.mp3
    Song-6.mp3
    Song-7.mp3
```


Now let's say you copy your organized music from `PC_ROOT_PATH_TO_MUSIC_COLLECTION`
to a location on your phone's SD_CARD, say at `<SD_CARD_ROOT>/MY_MUSIC_COLLECTION`. Henceforth this path will referred to as `SD_CARD_ROOT_PATH_TO_MUSIC_COLLECTION`.

Now let's say on your phone you wish to create following playlists containing mentioned songs:

* `Playlist-1` containing songs at following paths:

```
SD_CARD_ROOT_PATH_TO_MUSIC_COLLECTION/Song-1.mp3
SD_CARD_ROOT_PATH_TO_MUSIC_COLLECTION/Song-2.mp3
SD_CARD_ROOT_PATH_TO_MUSIC_COLLECTION/Song-3.mp3
```

* `Play_list_2` containing songs at following paths:

```
SD_CARD_ROOT_PATH_TO_MUSIC_COLLECTION/folder_1/Song-4.mp3
```

* `playlist-3` containing all songs under `SD_CARD_ROOT_PATH_TO_MUSIC_COLLECTION/folder_1/folder_1_1`

To generate above playlists using this utility, you will first need to create a JSON file named, say `nokia_phone_playlists_data.json`, at a desired location say `/home/jignesh/my_nokia_playlists`.

Then open that JSON file in a text editor and add following contents to it:

```
{
  "pc_root_path_to_music_collection": "/home/jignesh/MY_MUSIC_COLLECTION",

  "sd_card_root_path_to_music_collection": "E:/MY_MUSIC_COLLECTION",

  "playlists_output_folder": "/home/jignesh/generated_playlists",

  "playlists": [
    {
      "name": "Playlist-1",
      "music_track_paths_relative_to_pc_root_path": [
        "Song-1.mp3",
        "Song-2.mp3",
        "Song-3.mp3"
      ]
    },
    {
      "name": "Play_list_2",
      "music_track_paths_relative_to_pc_root_path": [
        "folder_1/Song-4.mp3"
      ]
    },
    {
      "name": "playlist-3",
      "music_track_paths_relative_to_pc_root_path": [
        "folder_1/folder_1_1"
      ]
    }
  ]
}
```

Henceforth the JSON file will referred to as `PLAYLISTS_DATA_JSON_FILE`.

_**Note**_

* In `paths_relative_to_pc_root_path` individual file-names can be specified,   or a folder-name can be specified.

  If individual file-name will be specified, then only the mentioned files will be added to the playlist.

  If folder-name will be specified, then all the files directly inside that  folder will be added to the playlist. Note that nested folders, if any, inside that folder-name will be ignored. To copy files from the nested-folder the nested-folder name will need to be explicitly specified.

* `PLAYLISTS_DATA_JSON_FILE` must be a valid JSON file. When adding a lot of entries to `playlists` Array property it is possible to make a mistake like missing a quote or comma etc causing the JSON file to become invalid. Considering that it is recommended to validate the JSON contents against an online validator like [jsoneditoronline](https://jsoneditoronline.org).


Once the `PLAYLISTS_DATA_JSON_FILE` is ready, open a terminal on your PC and change directory to this utility's root folder like following

```
$ cd <UTILITY_ROOT>
```

wherein

`<UTILITY_ROOT>` should be path to this utility's root folder. Refer **Usage prerequisites** section before for more details.

Then change to following directory

```
$ cd phone_model/nokia_220_4g_2024
```

Then run following command:

```
$ ruby generate_playlists.rb <playlists_data_file_path>
```

wherein

`<playlists_data_file_path>` should be path to `PLAYLISTS_DATA_JSON_FILE` you created before. For e.g. `/home/jignesh/my_nokia_playlists/nokia_phone_playlists_data.json`

That command should generate following files in `playlists_output_folder` property specified in `PLAYLISTS_DATA_JSON_FILE`.

```
Playlist-1.lst
Play_list_2.lst
playlist-3.lst

playlists_index
  listinfo.data
```

**With this playlists generation is complete and the next step would be
to transfer those generated files to the phone.**

# Transferring generated playlists to the phone

Connect the phone to your PC using the data-cable by connecting USB Type-A end on PC's USB port) and USB Type-C end on phone's USB port.

Once connected, on phone you should see options like following

* Charging only
* Phone memory

*Note: On my Nokia 220 4g model mentioned in **Introduction** section above were the options available.*

Select **Phone memory** option and on your PC two mount points will be visible:

1. For SD_CARD like "31 GB Volume"

2. For phone like "Nokia2204g".

Click on SD_CARD's mount-point and navigate to `System/Mp3_res` folder and copy generated playlist files ( i.e. `Playlist-1.lst`, `Play_list_2.lst`, `playlist-3.lst`) into it.

Then click on phone's mount-point and navigate to `System/Mp3_res` folder and there you should find the `listinfo.data` file generated by the phone's software. *For safety purpose you can rename it to `original_listinfo.data`*.

Then copy the generated `listinfo.data` file from `playlists_index` folder
and copy it to the phone's mount-point's `System/Mp3_res` folder.

_**Note:**_

*The generated `listinfo.data` file contains entries to the generated playlists. If you copy only the generated playlist files to SD_CARD's mount-point's `System/Mp3_res` folder, then the phone's music-player's Playlists interface will not show your copied playlists.The reason being when creating a playlist through phone, then in addition to creating it the phone's software also updates `listinfo.data` by adding an entry to the created playlist.*

Once the copying of generated files is done, unmount the mount points on PC
and the PC would say something like *it is safe to eject the removable drive*.

Once that is done, go to phone's music-player and check the Playlists interface and you should find the entries for generated playlists. Click one and you should see the songs added to that playlist. Click one and it should play!!
